# Procurement landing page concept

Generated using the built-in image generation tool.

## Prompt specification

Create a polished desktop UI mockup for VCL Compass Procurement using a white and pale blue-grey background, indigo accents, readable typography, restrained borders and generous whitespace.

Retain the app sidebar and Global Search. Show a prominent unified document search supporting supplier, document reference, BL, container, item name and item code, followed by document-type filter buttons. Include four common task actions, a compact Needs attention panel, and four Browse documents links. Use a warehouse icon for Stores.

Task actions: Raise Material Request, Raise Purchase Order, Receive Goods, Create Purchase Invoice. Emphasise Create Purchase Invoice. Receive Goods is a proposed shortcut subject to workflow validation.

Document filters: All, Material Requests, Purchase Orders, Purchase Invoices, Receiving.

Illustrative attention rows: Orders past due (12), Receipts awaiting invoices (8), Invoice drafts to submit (5). Label counts as examples.

No full document table, charts, financial totals or oversized metric cards. Label the image DESIGN PROPOSAL and include a note that it is a concept for review.
